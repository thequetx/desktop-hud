# Desktop HUD user manual

Desktop HUD puts small, see-through "bubbles" in the corners of your Windows desktop: the time, what's next on your calendar, and, if you keep notes, this week's priorities. Clicks pass straight through the bubbles to whatever is underneath. When you step away, a calm idle screen fades in.

It works with no account, no notes and no calendar. It becomes useful once you paste a calendar link, and more so if you point it at a folder of Markdown notes, which it only reads unless you allow writing.

## In one paragraph each

**What it reads.** Your calendar links and .ics files, every 15 minutes. Markdown notes in the folder you choose, if you choose one. What your music app reports to Windows' media controls.

**What it writes.** In its own folder: settings, a calendar cache and its built-in notes. In *your* notes folder: nothing, unless you turn writing on. Then it writes two things only (see [Notes](notes.md#what-gets-written)).

**What it sends.** Nothing, except fetching your own calendar links. There is no account, no analytics and no telemetry. Logs stay on your PC. (A manual update check is planned; it will only ask GitHub for the latest version number.)
